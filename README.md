# CNotes - Online Learning & Testing Platform

Welcome to **CNotes**, a premium Single-Page Application (SPA) designed to provide top-tier educational materials and interactive online assessments.

## 🚀 Features

- **Modern UI/UX**: Built with a stunning Glassmorphism design, vibrant gradients, and dynamic background animations.
- **Single Page Application (SPA)**: Smooth and lightning-fast navigation without page reloads, built using Vanilla JavaScript event delegation.
- **Course Contents**: Structured and easily accessible study materials for:
  - Data Science (DS)
  - Business Information Technology (B-IT)
  - Big Byte (BB)
  - Advanced Engineering (ADVE)
- **Online Assessments**: Integrated test portals with motivational thoughts to help students excel in their exams.
- **Responsive Design**: Fully optimized for seamless viewing across mobile, tablet, and desktop devices.
- **Interactive Feedback System**: Built-in feedback form with animated submission states.

## 🛠️ Technologies Used

- **HTML5**: Clean, semantic markup.
- **CSS3**: Advanced styling including CSS variables, Glassmorphism, animations, flexbox, and grid layouts.
- **Vanilla JavaScript**: Unobtrusive JS, strict mode, and efficient DOM manipulation.
- **FontAwesome**: Modern icons.
- **Google Fonts**: Outfit font family for premium typography.

## 📂 Getting Started

To run this project locally, simply clone the repository and open the `index.html` file in any modern web browser. No complex build tools or servers are required!

```bash
git clone https://github.com/ankitsharma1105/CNotes.git
```
